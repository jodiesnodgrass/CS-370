# CS-370

What code were you given?

For this project, I was provided with starter code that established the core environment infrastructure, including the TreasureMaze class, the visual maze rendering tools, and the basic neural network structure. My main task was implementing the full Deep Q-Learning algorithm inside the qtrain function. 

What code did you create yourself?

For this project I created the AI pirate that works through the game maze trying to find the treasure and win the game before a human player would. I wrote the code using a epsilon-greedy decision-making process, integrated the experience replay memory buffer, managed state transitions within the game loop, and built the evaluation logic to monitor win rates and trigger early stopping once the agent mastered the maze.

What do computer scientists do and why does it matter?

Computer scientists can take complex real-world problems and turning them into automated solutions using code and algorithms. This work matters because virtually every modern industry from medicine and aerospace to finance and entertainment relies on computational systems to function. By building intelligent models and efficient software, computer scientists help create tools that make everyday tasks safer, faster, and much easier to manage.

How do I approach a problem as a computer scientist?

Aproaching a problem like a computer scientist means breaking a huge overwhelming problem down into smaller logical pieces that a computer can actually execute. It starts with identifying what data you have coming in, what specific output I need, and which tools or data structures make the most sense for the job. From there, it is an iterative process from writing code, testing how it handles unexpected situations, looking at trade-offs in performance, and refining the logic until the solution runs smoothly.

What are my ethical responsibilities to the end user and the organization?

Building software comes with a real responsibility to make sure technology is safe, fair, and reliable. To the end user that means respecting privacy, keeping data secure, and ensuring AI models do not make biased or dangerous decisions. To the organization it means delivering well-documented, maintainable code that abides by industry standards, respects legal boundaries, and protects the company's systems and integrity.
